ROMAN Architecture

UML Diagram

Visual overview of the ROMAN application: startup composition, the core agent loop, dynamic skill loading, and the two entry flows through CLI and Mattermost bot mode.
Entry Points `main.py` starts either interactive CLI mode or Mattermost bot mode.
Core Engine `Agent` builds prompts, talks to the LLM, runs tools, and stores session state.
Dynamic Skills `SkillManager` discovers skills from `SKILL.md` and loads tools on demand.
External Systems The app depends on an OpenAI-compatible API, Mattermost, and optional skill backends.

CLI Sequence

How a user message moves through the terminal interface and the agent loop.

sequenceDiagram
autonumber
actor User
participant CLI as main.py / run_cli()
participant Agent
participant Sessions as InMemorySessionStore
participant Skills as SkillManager
participant LLM as OpenAIClient
participant Tool as Skill Tool

User->>CLI: Enter message
CLI->>Agent: chat(user_input, session_id)
Agent->>Sessions: get_or_create(session_id)

loop up to MAX_TOOL_ROUNDS
  Agent->>Agent: _build_system_prompt()
  Agent->>Agent: _collect_tools()
  Agent->>LLM: chat(messages, tools, temperature)

  alt LLM returns tool_calls
    LLM-->>Agent: tool calls
    alt load_skill requested
      Agent->>Skills: load_skill(skill_name)
      Skills-->>Agent: instructions + tools + references
    else collect_context requested
      Agent->>Agent: normalize request / detect missing fields
    else skill tool requested
      Agent->>Tool: execute(**args)
      Tool-->>Agent: result
    end
  else LLM returns final content
    LLM-->>Agent: final response
    Agent->>Sessions: save(session)
    Agent-->>CLI: response text
  end
end

CLI-->>User: Render markdown/text reply

Bot Sequence

How Mattermost events are filtered, converted to agent input, and posted back to the thread.

sequenceDiagram
autonumber
actor User
participant MM as Mattermost
participant Bot as MattermostBot
participant Agent
participant Sessions as InMemorySessionStore
participant LLM as OpenAIClient
participant Tool as Skill Tool

User->>MM: Post message in configured channel
MM-->>Bot: WebSocket "posted" event
Bot->>Bot: Filter by channel / ignore own messages
Bot->>Bot: Check mention or active thread
Bot->>Bot: Build session_id from root_id
Bot->>Agent: chat(message_text, session_id, metadata)
Agent->>Sessions: get_or_create(session_id)

loop tool-calling conversation
  Agent->>LLM: chat(messages, tools, temperature)
  alt tool calls
    LLM-->>Agent: tool calls
    alt dynamic skill loading
      Agent->>Tool: execute load_skill / collect_context / skill tool
      Tool-->>Agent: result
    end
  else final response
    LLM-->>Agent: final text
  end
end

Agent->>Sessions: save(session)
Bot->>MM: Post reply into thread
MM-->>User: Thread response visible
